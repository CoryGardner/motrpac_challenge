What is the fingerprint identifying?

Any multi-tissue study processes each tissue as a unit — one extraction plate, one library batch, one flowcell — so within-study accuracy alone leaves open how much of a fingerprint is biology. We measured how much processing could contribute in MoTrPAC, using the consortium's own reference-standard RNA pools run on every plate, and settled the question with an independent laboratory.
