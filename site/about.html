The challenge

Molecular Tissue Fingerprints — Can molecular signatures identify a tissue reliably?
Use one or more omics layers to predict tissue identity and determine whether a compact, interpretable signature is sufficient. Data: individual-sample rat endurance-training data across a selected set of tissues, with GTEx or another tissue resource for external context.

Stanford Bioinformatics Center / MoTrPAC Hackathon, 25–27 September 2026. Rules: at least one MoTrPAC component, at least one CFDE component, an open-source repository as the deliverable.

Data sources and licences

  • MoTrPAC 6-month rat endurance-training study, portal release c1.0 (rn6), as the R package MotrpacRatTraining6moData 2.0.0, exported to CSV once with R/export_motrpac.R. MoTrPAC data are released under the consortium's data-use terms; the study is MoTrPAC Study Group, Nature 629:174–183 (2024).
  • Rat BodyMap, GEO GSE53960 (Yu et al., 2014), via the Bioconductor package bodymapRat: 316 samples, 11 organs, 4 ages, technical runs summed. Public domain data (GEO).
  • GTEx v8 open-access gene expression (release 2017-06-05, RNASeQCv1.1.9 TPM and read counts) and sample attributes; ≤ 150 donors per tissue. GTEx open-access data are free to use under the GTEx data-use policy.
  • Orthology: the rat-to-human table shipped with the MoTrPAC package (1:1 pairs only used here).

No data file is in the repository: data/raw/ (1.9 GB) is the R-package export and data/external/ (5.8 GB) the GTEx and BodyMap downloads; both are recreated by the scripts in R/ and scripts/11_gtex_prepare.py, scripts/12_bodymap_prepare.py. The portal download of the full study (~128 GB) is not needed for anything on this site except the consortium QC table used by phase 16, which the script falls back from to the package metadata.

Competition compliance

  • MoTrPAC component: the dataset itself: 899 transcriptome vials of 50 rats in 19 tissues, plus the proteomics, metabolomics, immunoassay, ATAC and methylation metadata used for the identifiability audit.
  • CFDE component: GTEx, a CFDE Data Coordinating Center: GTEx v8 expression for the cross-species transfer (2,485 samples, 862 donors, 17 tissues). Cross-reference: the MoTrPAC rat metabolomics used in the multi-omic layers are also deposited at the Metabolomics Workbench (a CFDE DCC) as project PR001020; this analysis read them from the MoTrPAC package.
  • Open source: all code and the site are MIT-licensed; the data are not redistributed.

How to reproduce

conda activate motrpac-py            # environment specs in ../../docs/setup/
make test                            # leakage, I/O, conformal and site tests
make all bodymap gtex                # the analysis phases (about 1 h on 20 cores)
make identifiability                 # phase 16: batch nesting and the QC-only baseline
make site                            # regenerate results/31_site_regen, site/data and run the site tests
python -m http.server -d site 8000   # then open http://localhost:8000

Every page's figures name the results/ file they come from; site/data/provenance.json records file, row and column for every headline number.
