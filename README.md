# Stanford Multi-omics Hackathon 2026 Track 3

## Molecular Tissue Fingerprints

*Can molecular signatures identify a tissue reliably?*

### Challenge

Use one or more omics layers to predict tissue identity and determine whether a compact, interpretable signature is sufficient.

### Data

Individual-sample rat endurance-training data across a selected set of tissues, with [GTEx](https://gtexportal.org/) or another tissue resource for external context.

### Potential Outputs

- A classifier
- Minimal tissue-signature panel
- Feature-selection workflow
- Interactive model-explanation tool

> [!IMPORTANT]
> Evaluation must prevent animal-level data leakage and compare performance with simple baselines.
